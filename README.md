# YouTube Music Auto

API 없이 로컬 Mac에서 실행하는 재즈 영상 제작 도구입니다.

## 실행

Finder에서 start.command를 더블클릭합니다.

또는 터미널에서:

    python3 run.py

브라우저에서 http://127.0.0.1:8765 가 자동으로 열립니다.

## 사용 순서

1. 영상에 쓸 썸네일 이미지를 등록하고 테마를 입력해 프로젝트를 만듭니다.
2. 프로그램이 이미지의 분위기를 분석해 Suno_Prompts.txt를 만듭니다.
3. 생성된 프롬프트로 Suno에서 음악을 만들고, 화면의 버튼으로 음악 폴더를 열어 파일을 넣습니다.
4. 파일 확인 후 영상 만들기를 누릅니다.
5. 완료 후 결과 폴더에서 YouTube_Final.mp4와 업로드 문구를 확인합니다.

썸네일 이미지는 JPG, PNG, WEBP를 지원하며 최소 640×360, 20MB 이하여야 합니다.
등록한 이미지는 그대로 영상의 고정 화면(Cover.jpg)으로도 사용됩니다.

음악 파일은 이름순으로 재생되므로 01_, 02_처럼 번호를 붙이세요.
음악 구성은 홀수 번호가 가사·보컬곡, 짝수 번호가 연주곡으로 번갈아 진행됩니다.

## 분위기 분석

외부 API를 쓰지 않고 이미지의 밝기, 채도(절대 채도), 명암 대비, 색온도를 로컬에서 측정해
네 개의 분위기 태그와 Suno용 음악 지시문으로 바꿉니다. 분석 결과는 프로젝트 폴더의
Cover_Mood.txt에서 확인할 수 있습니다. 색상 기반 분석이므로 장면이나 사물은 인식하지 않습니다.
