# Screen Flow
> Created: 2026-08-11 13:53
> Last Updated: 2026-08-15

## 1. 화면 목록

1. 설정 점검 화면: FFmpeg와 FFprobe 준비 상태를 표시한다.
2. 썸네일·테마 입력 화면: 썸네일 이미지를 등록하고 테마를 입력해 제작을 시작한다.
3. 제작 진행 화면: 현재 단계, 진행 상태, 오류와 재시도를 표시한다.
4. 결과 화면: 생성 파일, 영상 길이와 검사 결과를 표시한다.

## 2. 사용자 흐름

```text
프로그램 실행
-> 설정 점검
-> 썸네일 이미지 등록
-> 테마 입력
-> 제작 시작
-> 썸네일 분위기 분석
-> 분위기를 반영한 음악 제작 지시서 생성
-> 사용자가 Suno 음악 준비
-> 파일 확인 후 로컬 영상 제작 진행
-> 자동검사
-> 결과 확인
-> 결과 폴더 열기
-> YouTube Studio에서 직접 업로드
```

모든 상태는 한 페이지의 세로 흐름으로 표시한다. 썸네일·테마 입력 영역 아래에 제작 진행 단계가 순서대로 활성화되고, 마지막 단계가 끝나면 그 아래에 완료 결과가 나타난다.

썸네일은 파일 선택 또는 끌어다 놓기로 등록하고, 등록 즉시 화면에 미리보기를 표시한다. 분석 결과는 제작 진행 영역 상단에 네 개의 분위기 태그와 주요 색상으로 표시한다.

## 3. 화면별 데이터

| 화면 | 입력 | 표시 | 저장 또는 전송 |
|:---|:---|:---|:---|
| 설정 점검 | 없음 | FFmpeg와 FFprobe 상태, API 미사용 모드 | 없음 |
| 썸네일·테마 입력 | 썸네일 이미지 파일, 테마 문장 | 썸네일 미리보기, 채널 프로필 요약 | 프로젝트 생성 |
| 분위기 분석 결과 | 없음 | 분위기 태그 4개와 주요 색상 | 매니페스트 `mood` |
| 제작 진행 | 파일 확인·재시도 명령 | 단계, 진행률, 오류 | 로컬 파일과 중간 결과 |
| 결과 | 폴더 열기 | 결과 파일과 검사 상태 | 없음 |

## 4. 상태 처리

- 로딩: 현재 실행 중인 단계와 경과 시간을 표시한다.
- 빈 상태: 썸네일 등록 안내와 테마 입력 예시를 표시한다.
- 오류: 실패 단계, 원인, 해결 방법과 실패 단계 재시도 버튼을 표시한다.
- 파일 대기와 실행 실패는 서로 다른 안내 패널로 구분한다.
- 파일 대기: 음악 폴더 열기와 파일 준비 방법을 표시한다. 썸네일은 이미 등록되어 있으므로 안내하지 않는다.
- 입력 오류: 지원하지 않는 형식, 최소 해상도 미달, 용량 초과를 등록 즉시 입력 영역에 표시한다.
- 재개 가능: 완료된 단계와 다시 시작할 단계를 구분한다.
