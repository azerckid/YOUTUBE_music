## 1. 디자인 목표

사용자가 여러 설정을 매번 조정하지 않고 테마 한 문장에 집중하도록 한다. 제작 과정은 숨기지 않고 현재 상태와 실패 원인을 명확히 보여준다.

## 2. 기본 레이아웃

- 상단: 프로젝트명과 설정 상태
- 첫 번째 영역: 테마 입력과 제작 시작
- 두 번째 영역: 입력 영역 아래에서 순차적으로 갱신되는 제작 단계
- 마지막 영역: 모든 단계 완료 후 표시되는 결과 파일과 폴더 열기
- 입력, 진행과 결과를 좌우로 나누지 않고 위에서 아래로 이어지는 단일 페이지로 구성한다.

## 3. 핵심 CTA

- `제작 시작`: 테마를 확정하고 자동 제작을 시작한다.
- `실패 단계 재시도`: 완료된 작업을 유지하고 실패 단계부터 재개한다.
- `결과 폴더 열기`: 업로드할 결과 파일을 Finder에서 연다.

## 4. 상태별 UI

- 기본: 테마 입력창과 제작 시작 버튼
- 생성 중: 단계명과 진행률. 1차 버전은 화면 내 중단 버튼을 제공하지 않는다.
- 대기 중: Suno 음악과 대표 이미지 파일 준비 상태
- 오류: 실패 단계, 오류 요약, 사용자 조치와 실패 단계 재시도 버튼
- 완료: 결과 파일, 영상 길이, 검사 통과 상태

## 5. 접근성과 사용성

- 진행 상태를 색상만으로 구분하지 않고 텍스트와 아이콘을 병행한다.
- 버튼에는 실행 결과를 예측할 수 있는 명확한 동사를 사용한다.
- 오류 메시지는 서비스명, 실패 작업과 해결 방법을 포함한다.
- 기본 반응은 400ms 이내에 표시하고 장기 작업은 즉시 진행 상태로 전환한다.
