# Product Specifications
> Created: 2026-08-11 13:53
> Last Updated: 2026-08-15

## 1. 제품 정의

로컬 Mac에서 실행되는 YouTube 재즈 영상 제작 자동화 프로그램이다. 최종 목표는 사용자가 테마를 입력하면 외부 생성 서비스와 FFmpeg를 이용해 업로드 직전 결과물을 만드는 것이다.

1차 버전은 외부 API를 사용하지 않는다. 사용자가 썸네일 이미지와 테마를 입력하면 프로그램이 이미지의 분위기를 분석해 음악 제작 지시서를 생성하고, 사용자가 Suno 음악을 준비하면 이후 미디어 조립과 결과물 생성은 로컬에서 자동 처리한다.

## 2. 실행 입력

- 필수 입력: 썸네일 이미지 파일 1장, 테마 한 문장
- 썸네일 제약: JPG·PNG·WEBP·TIFF, 최소 640×360, 20MB 이하
- 1차 버전 일회성 설정: 채널 프로필과 출력 폴더
- 추후 완전 자동화 설정: Suno API 키와 이미지 생성 API 키
- 고정 제작 규칙: 홀수 곡은 가사·보컬곡, 짝수 곡은 연주곡, 곡 세트 3회 반복, 1080p, 24fps, H.264, AAC

## 3. 실행 순서

1. 썸네일 이미지 등록과 테마 입력
2. 썸네일 분위기 분석과 제작 방향 결정
3. 분위기를 반영한 Suno용 곡 제목과 곡별 프롬프트 파일 생성
4. 사용자가 Suno에서 음악을 생성해 지정 폴더에 저장
5. 등록한 썸네일 이미지에 제목과 보조 문구 합성
6. 곡 순서와 실제 재생시간 분석 및 챕터 계산
7. 음악 세트를 연결하고 3회 반복
8. 대표 이미지와 음악을 결합해 MP4 생성
9. 제목, 설명, 곡 목록, 챕터와 해시태그 생성
10. 완성 영상 자동검사
11. 업로드용 결과 폴더 구성

## 4. 결과물

```text
OUTPUT/<project-slug>/
├── YouTube_Final.mp4
├── Cover.jpg
├── Title.txt
├── Description.txt
├── Chapters.txt
├── Upload_Info.txt
└── Generated_Tracks/
```

`Cover.jpg`는 영상의 고정 화면과 YouTube 썸네일에 동일하게 사용한다. 별도 썸네일은 생성하지 않는다.

## 5. 기능 요구사항

- FR-01: 사용자는 테마를 입력하고 제작을 시작할 수 있어야 한다.
- FR-02: 프로그램은 등록된 썸네일 이미지의 밝기·채도·대비·색온도를 로컬에서 분석해 분위기 태그와 음악 지시문으로 변환해야 한다.
- FR-02a: 프로그램은 테마와 분석된 분위기를 함께 음악 제작 지시서로 변환해야 한다.
- FR-03: 프로그램은 1·3·5·7번을 가사·보컬곡으로, 2·4·6·8번을 연주곡으로 지정한 Suno 프롬프트와 제목을 생성해야 한다.
- FR-04: 프로그램은 Suno API 결과를 곡 순서대로 저장해야 한다.
- FR-05: 프로그램은 등록된 썸네일을 16:9로 맞추고 제목을 합성해야 한다.
- FR-06: 프로그램은 실제 곡 길이를 측정해 첫 세트 챕터를 생성해야 한다.
- FR-07: 프로그램은 전체 음악 세트를 3회 반복해야 한다.
- FR-08: 프로그램은 YouTube 호환 MP4를 생성해야 한다.
- FR-09: 프로그램은 보컬곡과 연주곡의 혼합 구성을 정확히 설명하는 업로드 문구와 생성 기록을 저장해야 한다.
- FR-10: 프로그램은 실패 단계부터 안전하게 재시작할 수 있어야 한다.

### 1차 버전 수동 경계

- 음악 생성과 썸네일 이미지 준비만 사용자가 직접 수행한다.
- 프로그램은 `Suno_Prompts.txt`, `Cover_Mood.txt`와 음악 입력 폴더를 제공한다.
- 썸네일은 프로젝트 생성 시점에 등록되므로 별도 이미지 제작 지시서를 만들지 않는다.
- 음악이 준비된 이후 단계는 추가 API 없이 자동 실행한다.

### 분위기 분석 경계

- 분석은 Pillow 기반 색상 통계만 사용하며 외부 비전 API를 호출하지 않는다.
- 장면, 사물, 인물 인식은 범위에 포함하지 않는다.
- 분석 결과는 프로젝트 생성 시점에 확정되며 이후 이미지를 교체해도 다시 계산하지 않는다.

## 6. 비기능 요구사항

- API 키를 결과물과 로그에 노출하지 않는다.
- 외부 API 요청과 비용 추정치를 프로젝트별로 기록한다.
- 한글, 영문, 공백이 포함된 테마와 파일명을 처리한다.
- 썸네일 분석은 사용자가 대기를 느끼지 않도록 프로젝트 생성 응답 안에서 끝낸다.
- 기존 참고 MOV보다 정지 영상에 적합한 효율적인 파일 크기를 목표로 한다.
- 중간 산출물을 보존하여 전체 작업을 처음부터 반복하지 않는다.

## 7. MVP 제외 범위

- YouTube API 자동 업로드
- 별도 썸네일 디자인
- 영상 애니메이션과 장면 전환
- 모바일 앱과 다중 사용자 계정
- 자동 공개 또는 예약 설정
- 외부 생성 서비스의 웹 화면 자동조작

## 8. 외부 제약

- Suno API의 상세 계약과 과금은 계정 로그인 후 확인해야 한다.
- OpenAI API는 ChatGPT 구독과 별도로 과금된다.
- AI 생성 결과의 미적 품질은 자동검사만으로 완전히 보장할 수 없다.
